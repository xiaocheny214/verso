Verso · Portrait Algorithm · Issue #63

证据先于画像，模型只负责判别

知乎内容先变成最小化证据，LLM 判断“展示能力 / 仅有兴趣 / 不确定”，确定性规则再生成可匹配画像；不确定项不晋升，空画像走自报。

判断边界

LLM 只把证据归入闭集标签并判断能力信号；收藏、关注和提问默认不是“能教”。

确定性核心

阈值、时间窗、去重和持久化由领域规则负责，同样输入可复测。

安全出口

模型不可用或证据不足时宁缺毋滥，保留旧画像；空画像可由用户自报。
